# flask-redis-multi-container

A hands-on project exploring docker flask and redis, with the aim of building and running a multi-container application.

The application uses Flask to serve two routes, a welcome page and a visit counter. Redis acts as the key-value store, keeping track of the number of visits.

I'm using this project to develop my understanding of containerisation, service communication and how individual components work together.

Along the way, I'll be documenting challenges, troubleshooting steps and key learnings, including Redis persistence, environment variables, container scaling and load balancing.

This is a work in progress, and I'll continue updating the repository as the project develops.
